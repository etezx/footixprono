RÈGLEMENT FOOTIX PRONO

Les règles de jeu sont simples : pronostiquer pour le plaisir, respecter les autres et jouer avec un seul compte.

01

PARTICIPATION

La participation aux pronostics communautaires est gratuite, sans achat ni mise d'argent. Un seul compte est autorisé par personne. Le pseudo doit rester approprié et ne pas usurper l'identité d'un tiers.

02

PRONOSTICS & BARÈME

Pour chaque match, le joueur pronostique un score. Le pronostic peut être modifié jusqu'au coup d'envoi affiché, puis il est verrouillé. Score parfait : +3 points. Bonne issue (victoire, nul ou défaite) avec un score différent : +1 point. Mauvaise issue : 0 point. Exemple : pour un pronostic 3–1, un résultat final de 3–1 rapporte 3 points ; un résultat de 2–0 rapporte 1 point ; un match nul ou une victoire de l'équipe adverse rapporte 0 point. Les points sont attribués uniquement lorsque le match est terminé.

03

CLASSEMENT MENSUEL

Le classement récompensé court du premier au dernier jour civil de chaque mois, selon l'heure Europe/Paris. Seuls les matchs dont le coup d'envoi appartient au mois concerné et dont le résultat est définitif sont comptabilisés. Les points sont attribués selon le barème ci-dessus : 3 points pour un score parfait, 1 point pour une bonne issue et 0 point pour une mauvaise issue. Le taux de réussite correspond à la proportion de matchs pour lesquels la bonne issue (victoire, nul ou défaite) a été trouvée. Le classement est recalculé après chaque résultat définitif.

04

RÉCOMPENSES

Les trois premières places mensuelles correspondent aux niveaux Or, Argent et Bronze. La nature et la valeur exactes des lots sont publiées avant le début du mois récompensé. En cas d'égalité de points, le meilleur taux de réussite départage les joueurs ; si l'égalité subsiste, le dernier bon pronostic enregistré le plus tôt est prioritaire. Aucun achat n'est nécessaire pour participer ou gagner.

05

ÉLIGIBILITÉ

Pour recevoir une récompense, le compte doit notamment disposer d'un email confirmé, avoir accepté les règles applicables, être actif et ne pas avoir été bloqué pour fraude. Le gagnant est contacté par email pour la validation finale.

06

ANTI-FRAUDE

Les multi-comptes, manipulations, automatisations abusives et tentatives de contournement peuvent entraîner l'exclusion d'une récompense ou la suspension d'un compte. Une adresse IP commune ne constitue pas, à elle seule, une preuve de fraude.

07

MATCH REPORTÉ / ANNULÉ

Les modalités applicables aux matchs reportés, interrompus ou annulés sont précisées pour chaque période récompensée avant son lancement afin de conserver les mêmes règles pour tous.

08

ESPRIT COMMUNAUTAIRE

Les contenus insultants, discriminatoires, illégaux, publicitaires ou destinés à perturber le service peuvent être modérés ou supprimés. Les suggestions restent les bienvenues dans l'espace communautaire à venir.

IMPORTANT AVANT LE PREMIER CONCOURS AVEC LOT

Cette version prépare le fonctionnement du site. Avant d'ouvrir une période avec récompense, les informations manquantes — lot exact, valeur, dates, départage, délai de réponse et modalités de remise — devront être figées et publiées. Une vérification juridique professionnelle est recommandée avant le premier concours public doté.
